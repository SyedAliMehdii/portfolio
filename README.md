# Personal Portfolio Website

A clean, modern, and fully responsive personal portfolio website showcasing my skills, projects, and experience as a Generative AI Specialist. 

## Features
- **Modern UI/UX**: Designed with a sleek, dark-themed aesthetic and glassmorphism elements.
- **Responsive Design**: Flawlessly adapts to desktop, tablet, and mobile devices.
- **Dynamic Content**: Easy to update projects, skills, and experience sections.
- **Performance Optimized**: Lightweight and fast-loading with smooth scrolling.

## Technologies Used
- HTML5
- CSS3 (Custom Variables, Flexbox, CSS Grid)
- JavaScript (Vanilla JS for DOM manipulation and animations)
